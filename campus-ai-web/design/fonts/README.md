DEV-only copy of the task's licensed Campthink Export Sans Regular font and SIL
OFL, used to generate real synthetic PDF files in the standalone design review.
The browser serves this asset from its own normal project root. No Vite filesystem
allowlist or authentication setting is widened. This design tree is not packaged
in the production web bundle. The authoritative source/provenance and generator
are in campus-ai-server/src/main/resources/fonts and tools/prepare_export_font.py.
