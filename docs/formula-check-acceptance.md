## 新功能在哪里

我的项目 → 数据检查 → 公式复算与结果核对。

1. 粘贴/导入带表头的数据，保留真实来源
2. 选择数量×单价、变化率、毛利率，或输入有限自定义算式
3. 对应x/y数据列，填写变量和结果单位；可选已有结果列及允许绝对差
4. 核对适用条件并确认，逐行复算
5. 结果显示原始行号、实际输入、复算值、原结果、绝对差及无法计算原因
6. 保存设置随项目版本保留；版本对比、Markdown导出和明确勾选数据分享的审阅快照都包含设置

免费、本机计算、不调用模型、不覆盖原始数据。数据/算式/列设置变更清除确认状态，旧结果明确标记过期。每页20行，完整过程在导出中。不会把缺失当作0，不静默排除零除数或错误行。

## 实现边界

独立算术解析器，无eval/Function/属性访问/宿主函数/网络能力。只支持x、y、数值、括号、四则运算、abs和sqrt；最多200字符、128词元、16层括号或连续符号，输入和中间结果限定±10¹²。非法表达式、非有限数、零除数、负数开实数平方根、乘除下溢均明确失败。

不是Excel公式执行器，不运行附件公式，不自动换算单位或验证量纲，也不证明数据真实、公式适用或专业结论正确。使用浮点运算，显示10位有效数字；比较使用完整计算精度和用户输入的绝对容差，不暗中增加容差。结果为%时以百分数表示，如20%填20。仅学习复核，不能作为设备或车辆操作依据。

Word导入补充表格编号/行号、制表符和换行。删除/移出修订文字忽略，插入/移入文字保留并提示核对。合并/嵌套表格结构不保真，无OCR、图片、公式和页眉页脚读取。
