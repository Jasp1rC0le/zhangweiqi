# 课表截图解析提速

用户要求加快课表截图及批量导入，并保持准确性和正常功能。本轮只优化服务器本地OCR执行；原图覆盖、版面识别、PPOCRv5模型、置信度、周次/学期/冲突校验和整批一次保存规则保留。

## 采用的优化

原先每张图都会启动Python并重新导入识别组件、加载同一模型。新版在已授权用户打开图片导入功能时预热一个本地工作进程，并在后续请求中复用模型权重。请求通过有界标准输入/输出传递，逐次随机标识、图像尺寸、区域顺序和可靠性仍校验；不缓存用户截图或解析结果。临时图片及区域文件逐次删除，空闲60秒释放模型；启动超过30秒、请求超时、异常退出及应用关闭均有受控清理。

本轮试过减少锚点读取范围，但无法稳定取得完整学期/周次，回退后反而更慢，已撤掉。线程数调整也未显示稳定提速，未采用。正式代码继续读取完整图片，没有缩小图片、换小模型、降低置信度或省略核对字段。
