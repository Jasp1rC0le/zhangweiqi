# 后台本地课表截图识别

2026-10-26。截图上传接口改为本地 OCR 和确定性版式解析，不调用大模型，不消耗模型 Token 或 AI 配额。聊天查课的模型回答功能独立保留。

## 使用

课表 → 导入课表 → 选择 PNG/JPG 截图。2026-10-27 起，上传后自动识别并保存，不再逐行勾选、预览或二次确认；随后打开导入课程所在日期。一次最多 2MB、120 行。只采用图片明确显示的周次；同学期单周截图替换该周，其他周保留。未知教师留空，不按姓名绑定教师账号。已有课程中的明确教师信息在同名、同日、同时间及同教室唯一匹配时保留。

当前针对学校移动端的七列星期、左侧节次、彩色课程块适配；不支持的版式明确拒绝，不猜课程。模糊文字、罗马数字等可能识别错误，需对照原图修改。截图只有一周时不能据此补全整学期。

## 运行环境

- macOS：使用系统 Apple Vision，通过 `/usr/bin/swiftc` 将随 JAR 的 Swift 源码编译为本机程序。需要可用的 Xcode Command Line Tools；已在当前 Mac 运行实测。
- 2026-10-27 修复运行环境差异：编译前用 `xcrun --sdk macosx --show-sdk-path` 解析当前选定工具链的 SDK，并在本机 OCR 子进程中排除继承的 `SDKROOT`。避免 GUI 启动的 Java 进程把另一套 Command Line Tools SDK 交给 Xcode Swift。没有修改系统开发工具选择或永久环境变量。
- Linux：可配置 `app.timetable.ocr.command` 为 Tesseract 的绝对路径，并安装 `chi_sim`、`eng` 语言数据。该分支尚未完成实际 Linux 图像验收。缺引擎或语言数据会拒绝识别，不回退外部服务。
- Spring 环境变量形式：`APP_TIMETABLE_OCR_COMMAND=/usr/bin/tesseract`。不接收用户提供的命令或 Shell 参数。

全局一次只执行一个识别任务，同账号不并发；总时限 75 秒，编译限 40 秒。认证、当前学校范围和图片格式/像素限制在处理前后复核。

## 数据边界

图片只在本站进程及本机 OCR 子进程之间处理。临时目录权限 700、文件 600，每次任务 finally 删除图片、识别输出及错误文件，退出时删除编译目录。不写公共文件库、对话、模型提示词或 AI 用量记录。新上传流程使用 `import-image` 自动保存，旧 `recognize-image` 只读接口保留兼容；原图片库接口是独立功能。保存时锁定账号范围并检查课表版本，过期请求不能覆盖新版本。

原 Kimi 图像适配类保留为历史兼容测试代码，已撤销 Spring 服务注册，公开截图接口只注入 `LocalTimetableOcrService`。

## 验证范围

提供的学校截图在实际 Apple Vision 和版式解析中得到 8 行，学期、2026-11-02 所在第 9 周、第 1 周周一 2026-09-07、节次和教室均提取。3 个课程名称中的罗马数字仍有歧义，新自动流程保留识别结果并提示可修改，不阻断保存、不宣称逐字无误。实际原图和识别正文不进入公开仓库。

复现私有图片测试需明确设置 `TIMETABLE_OCR_SAMPLE`（图片绝对路径），可选 `TIMETABLE_OCR_SAMPLE_RESULT`（私有输出路径），执行 `mvn -Dtest=LocalOcrProvidedImageTest test`。默认 CI 跳过该用例；其他解析、权限、并发和无外发契约采用合成数据测试。
