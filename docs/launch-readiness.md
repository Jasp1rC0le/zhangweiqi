# 上线前检查

本次更新是源码提交，不是生产部署。以下事项需要由目标环境运营者逐项确认：

- 独立数据库账号、完整 49 张必要表及适用于现有数据版本的迁移（包括四张私有课表表）；`/api/health/ready` 正常。
- 正确域名、HTTPS、Caddy 路由、可信来源和 Secure Cookie，禁止直接暴露内部 Java 端口。
- 与实际运营主体、第三方服务及保留期限一致的隐私文本和 `PRIVACY_*` 配置。
- 模型供应商、小额真实调用、SMTP 收发与找回流程；预算与单价按真实配置核对。
- 两个独立受控账号下的权限隔离、项目保存与审阅、导出、注销和会话撤销验证。
- 备份、加密、异地保存以及恢复到独立新库的演练。
- 目标地区实际适用的域名、备案和运营前提，由负责人核对。

`prod` 禁用自动建表，并校验部分安全与隐私参数；这些启动校验不能代替以上人工和真实环境验证。详见 [运行手册](free-launch-runbook.md)。
