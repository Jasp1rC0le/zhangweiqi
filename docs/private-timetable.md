# 私有课表

“我的课表”保存用户主动提供的图片和结构化课程。两类数据分别导入、预览及确认保存，仅登录账号本人可读写；不进入校园公共知识库，也不会发送给模型或学校服务。

## 导入与提醒

- 图片支持 PNG/JPEG。浏览器接受至多 8 MiB 原图，在解码前检查尺寸，压缩后提交；后端独立校验至多 2 MiB、1200 万像素及最大边长 10000，并重新编码以移除附加元数据。原图内容本身仍可能含姓名或学号，上传前应裁掉不必要的身份区域。
- 图片需确认学期、第 1 周周一日期及覆盖周次。单周图只代表该周；没有 OCR、从截图自动生成课程或推断全学期安排的功能。
- 课程文件为 UTF-8 CSV/TSV/TXT，至多 100000 字节、50000 字符。也可粘贴文本。列名为 `课程名称`、`星期`、`开始时间`、`结束时间`、`周次`、`教室`；教室可空，不接收身份或成绩等额外列。
- 每次保存 1—120 条安排，时间为 `HH:mm`，周次为 1—30，可使用范围、单双周及列表。预览会合并完全重复行、提示时间重叠，并列出相对已保存版本的新增、移除与未变项；用户确认后才提交。
- 核对提醒依据覆盖周次和上次核对时间，首页可显示明确导入课程中的下一节。提醒不表示系统发现了学校调课；普通网页关闭时没有后台推送保证。

## 账号隔离与冲突

接口位于 `/api/timetable` 与 `/api/timetable/courses`，依赖正常登录，私有响应禁止缓存。前端在退出、切换账号、取消和组件卸载时隔离旧请求；服务端校验版本，防止旧标签页覆盖新数据。冲突时应保留填写，读取最新版本后重新确认。

用户可以下载、核对和删除已保存内容，账户数据导出也包含私有课表。删除后仅保留不含图片或课程的账号版本计数以防止旧请求覆盖重建数据；账号注销通过外键级联删除。备份的留存与清除应由运营者按实际策略执行。

## 数据库升级

当前服务就绪检查包含 49 张表。已有数据库需要审查并应用 [2026-10-11-private-timetables.sql](../deploy/migrations/2026-10-11-private-timetables.sql)，新增 `student_timetable_versions`、`student_timetables`、`student_course_schedule_versions` 和 `student_course_schedules`。该文件只做加法建表；完整 `schema.sql` 仅用于独立空库初始化。本次源码准备没有执行数据库迁移。

## 验证边界

实现包含图片头校验、文件读取超时、账号隔离、版本冲突、删除重建及导出回归测试，当前执行结果见[发布验证](free-launch-acceptance.md)。合成测试不代表学校原生导出格式、真实学生账号联调、生产 HTTPS 或移动设备体验已经验收。项目不提供学校密码采集、自动登录、实时调课同步、截图 OCR 或外部识别服务。
