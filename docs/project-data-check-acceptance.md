# 数据检查第二轮：实现与验收记录

日期：2026-09-23。范围依据 `docs/project-studio-surface.md` 第二轮约定。

## 本轮交付

- 在登录后的项目工作台增加“数据检查”，保留已优化首页、介绍页和登录页。
- 支持粘贴或导入 UTF-8 CSV，保留原文及物理行号，预览前5条；上限为5万字、2000条数据、30列，文件导入另受100KB限制。
- 显式运行浏览器本地规则，检查表头、空值、列数与完全重复记录；用户选定实测/参考列、共同单位并确认后复算相对误差。参考值为0、不支持的数字和计算溢出不冒充成功结果。
- 展示问题原行、数值汇总及计算过程；结果绑定输入快照，修改后提示过期并禁止定位新材料。修改数据行保留列映射；表头变化时重置映射；CSV修改后须重新确认单位。
- CSV、来源和设置进入已有私有版本及 Markdown 导出。后端增加可选 DataSheet 与能力接口；旧项目可读取，旧后端未声明支持时拒绝写入并保留草稿，不需要新增数据库表。

## 继承视觉与交互

本轮是 Operate 工作台的普通扩展，沿用 Campthink 纸白背景、灰绿目录、深色文字、蓝色动作及现有字体。按钮和表格使用16px圆角，原行详情使用24px圆角；没有引入新视觉世界、字体、图片或全局设计系统文件。

新增区块复用工作台表单、问题列表、提示和焦点样式。移动端设置改为单列，操作可换行；宽表保留局部横向滚动，数字采用等宽数字特性。未生成 DESIGN.md 或设计侧车文件。

## 限制与交付状态

规则检查不调用模型、不消耗 Token；点击保存后才向私有项目服务提交数据。没有验证数据真实性、自动换算单位、统计显著性或专业结论；用户阈值不代表学校标准。数值使用浮点计算、展示最多10位有效数字；重复数据不自动删除，缺失不补0，表格公式不执行。

本轮未完成认证用户对真实 MySQL 的完整创建、保存、历史恢复及删除联调，未部署。当前运行服务健康不能证明它已经加载新增字段和能力接口；使用本轮保存能力前，运行环境必须载入本轮后端代码。
