# 项目工作台：本轮实施约定

最新修订（第四轮）：仅登录的ADMIN账号可见管理入口，服务器核验身份并复用同一登录会话。撤回下述第三轮公开入口方案。新增分部分原文版本对比、答辩/汇报准备；不改变既有视觉。师生均可处理自己的项目，不能跨用户读取。实际完成与未完成范围见 security-progress-acceptance.md。

2026-09-23 第三轮引导：工作台根据草稿给出一个可直接执行的下一步，跳到具体输入或要求；三类任务分别提供字段示例，示例不注入用户数据。材料支持选中原文后关联到要求，覆盖已有证据须确认，完成状态仍由用户勾选。没有CSV不阻挡基础检查。管理员入口在首页页脚、普通登录表单、聊天侧栏和工作台导航可见；管理员身份仍由独立会话与服务器验证，不依赖普通用户会话来隐藏入口。

Mode: Operate。沿用已确认的浅色 Campthink 操作界面；新增项目功能，不替换首页或聊天。

FIRST VIEWPORT：左侧可持续返回的项目目录，右侧显示当前任务及保存状态。初次进入展示具体输入说明及“创建项目”；有内容时直接进入任务，不播放开场动画。

PAGE MAP：目录 → 项目信息与原始任务书 → 要求确认 → 材料与证据 → 缺项检查 → 历史版本。只有确实支持的功能出现在可点击导航中。

VISUAL WORLD：继承 campthink.css 的纸白、灰绿侧栏、深色文字与蓝色动作；普通操作按钮16px、主要面板24px；不引入新字体或图像。不改全局设计系统。

LAYOUT：桌面目录与编辑器双栏，编辑器内分段表单和有编号的真实要求列表；手机目录改为紧凑选择器，操作换行，不把桌面侧栏挤进小屏。

INTERACTION：确认要求、补充证据后，缺项清单对应减少；结果明确属于当前草稿，保存后带版本号。未保存离开有提示，失败保留编辑内容，并发冲突拒绝覆盖。

CONTENT / BOUNDARIES：基础检查免费且不调用AI。仅纯文本导入，限100KB，支持手动粘贴。未运行专业工具，不能声称验证了数据、公式、引文或代码。恢复旧版是载入草稿，再保存为新版本；导出含材料和检查边界。

已确认：2026-09-23 用户回答“按这个顺序推进”。启动器权限不足，本轮不运行其命令、不变更权限；直接继承项目已有视觉，不进行视觉世界替换。

2026-09-23 第二轮扩展：用户明确保留全部已优化首页、介绍页和登录页，新能力只放登录后的工作台。新增“数据检查”步骤：CSV原文与前5行预览 → 来源／可选列映射与单位确认 → 明确运行 → 原行定位、计算过程、数值汇总 → 修改复查。结果对应输入快照，过期时禁止定位新材料；检查设置及CSV纳入已有私有版本和导出。基础检查免费且不发给模型，不冒充完整专业体检。旧后端不支持新字段时拒绝保存并保留草稿，无数据库表迁移。
