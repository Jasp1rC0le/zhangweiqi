# 课程详情与教室显示修复

用户截图显示详情文字散落在遮罩上，名称与地点难以阅读。根因是入口只加载了其他Element Plus组件样式，漏掉Dialog样式。现已加载Dialog及其依赖的基础样式，并为课程详情补上独立、限定范围的排版。

手机使用底部白色详情面板，桌面使用居中面板；课程名完整换行，日期/星期和时间集中显示，完整地点作为主要信息。详情不使用省略号或行数截断，长内容在面板内滚动，关闭按钮保持可见。教师、复制、关联及原点名/记录动作继承现有权限与数据逻辑。

周课表中优先显示来源中实际存在的教室号，如D-210、F2-418；体育馆显示楼层和场地名称。单节课保留教室号所需的两行。多个地点显示明确摘要，完整来源在详情保留；空地点显示待补，不猜教室，不改保存数据、识别结果或复制内容。
