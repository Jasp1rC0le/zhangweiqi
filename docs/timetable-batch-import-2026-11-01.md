# 批量课表导入 · 2026-11-01

用户要求多图批量导入、界面只留主要按钮、去掉导入确认。本批沿用既有工作区，不修改批准的登录动画、商家数据、学校权限或作息值。

## 功能与边界

一次可选1—20张PNG/JPG截图，每张2MB以内，总计32MB以内。选图后直接处理；服务器本地OCR持有同一个CPU槽，整批预算180秒、单图最多75秒。不外发模型、不消耗问答额度、不建后台任务或生产新表。

相同字节图片先去重，再识别明确学期、日期、星期、周次、课程和节次。全部图片须属于同一学期；同周完全相同课程去重，同周互不重叠的课程组合，不同周合并为明确周次集合。不会从一张图补造整学期。原课表只有本批明确覆盖的周被替换，其余周保留。

任一图片无法读取、周次/节次不清、学期不一致或同周课程重叠，整批不保存。全部验证通过后才进行一次版本保护的数据库提交；并发修改返回409，不自动重试。提交持有账号授权行锁并再次检查会话，处理期间退出、改密或撤销会话不能凭旧会话继续写入。不同未知节次不误继承教师，未知教师不补造。

表格文件与粘贴数据移除保存确认、勾选框和长差异介绍；完整且无冲突的数据自动保存。文件缺少可用的第一周周一日期时，仅显示必要日期字段，用户提供后自动继续，不猜校历。网络中断或停止等待只说明结果未确认，须只读刷新后再操作，不谎称已经撤销服务器处理。

## 界面

导入区去掉重复标题、大尺寸选图区、图片预览、常显帮助段落及课表说明。保留“截图/表格”“批量导入/导入表格”“返回课表”等动作，以及实际处理数量、结果或错误。可选多图的原生输入保留可访问名称、44px操作区、键盘焦点与既有系统颜色/动效。
