## 上课提醒

- 课表页新增上课提醒设置，默认关闭，提前量可选 5/10/15/30 分钟。开启后只通过受保护接口读取本人当天的已保存课表，不发给模型，不访问班级名单。
- 页面可见时核对提醒；后台、退出账号或相关模态框打开时暂停并清除旧状态。返回前台、跨日及课表变化后重新读取，已过上课时间不补发旧提醒。
- 同一课程按不含课程正文的事件摘要去重。支持的浏览器使用 Web Locks 协调多标签；未支持时采用存储去重降级，不承诺所有浏览器严格一次。设置和摘要只保留在当前浏览器，课程名、教室、教师不写入本地提醒存储。
- 课程没有明确钟点时不给出猜测提醒。数据读取、权限或时钟状态异常时显示重试/核对状态，不显示虚假的“已通知”。
- “加入手机日历”准备本人未来四周的 ICS 预览，可导出带 `VALARM` 的日历文件。取消课程不添加闹钟，上海时间转换为 UTC，稳定 UID 保持课程标识。准备和下载继续核对本人权限、源数据及文件 SHA。
- 网页内提醒需要页面保持开启；下载文件不等于已经导入手机日历。导入后的提醒由系统日历及通知设置管理，改课后须更新日历快照。没有将其宣传为已完成后台 Web Push。[Apple Web Push 条件](https://developer.apple.com/documentation/usernotifications/sending-web-push-notifications-in-web-apps-and-browsers)，[iCalendar 规范](https://www.rfc-editor.org/rfc/rfc5545.html)
