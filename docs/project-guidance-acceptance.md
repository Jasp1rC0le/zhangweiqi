# 工作台引导与管理员入口验收

日期：2026-09-23

历史记录：本文的公开管理员入口设计已被用户后续指示撤回；当前仅ADMIN可见入口，登录统一，详见 security-progress-acceptance.md。

## 本轮结果

- 原因：聊天入口原先依赖普通登录会话的ADMIN角色显示，且称为“审核中心”；与独立管理员会话不一致，普通登录页没有显式入口。
- 修复：首页底部、普通登录表单、聊天侧栏、工作台导航均有明确入口；后台继续使用既有独立会话与服务器权限校验，不授予普通用户管理权限。
- 工作台从命名、任务原文、核对要求、粘贴正文、关联证据到缺项检查，提示当前具体下一步并支持定位。
- 经管、汽轨/制造、通用任务分别给出输入格式示例；不自动填入示例材料或实验数据。
- 选中正文可直接关联要求，引用超过2000字、空白、失效选区不可关联；覆盖旧证据需确认；不会自动勾选完成。
