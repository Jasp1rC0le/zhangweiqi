# 2026年10月26日 易用性更新

> 本页记录当天第一批改动。后续版本已将截图改为后台本地 OCR、校园墙改为单正文框；当前行为见[本地 OCR 更新](local-timetable-ocr.md)，下方 Kimi 同意流程为历史说明。

本批围绕日期选择、课表导入和校园墙减少常驻说明，保持既有 Apple 工作区、四个主导航、登录和 Pro。

| 页面 | 现在如何使用 |
| --- | --- |
| 日期字段 | 点击日历图标选日期，可切换年月、用方向键及 Escape 操作；保留完整 ISO 日期手动输入。日期未应用时不会自动切换课表。 |
| 课表导入 | 从“导入/更新课表”进入专注导入视图，选择截图或表格。先上传、再核对课程，最后独立确认保存；取消后返回原查看日期。 |
| 截图识别 | 选图先本机预览。明确同意后才发往 Kimi 并计入已有额度；逐行校正、明确排除后进入差异预览。采用后收起识别区，避免重复操作。 |
| 表格文件 | JSON、XLSX、CSV 等按既有范围本机解析；服务识别失败时也能切换使用，不自动外发图片。 |
| 校园墙 | 日常吐槽、交友搭子、课程交流、实验求助；短介绍和图标配短标签，社区约定按需展开。发布仍审核，同校可见。 |
| 其他任务页 | 学习、项目、仪器、账户和反馈首屏文案简化，暂存说明按需展开。删除、隐私、发送及保存的必要后果保留。 |

截图导入当前仍使用配置的 Kimi 视觉服务，本批没有宣称已实现离线课表 OCR；文件文本提取与截图结构识别是不同流程。校园墙没有新增私信或不可追溯匿名承诺，旧分类 ID 保留，已有内容不迁移。

## 验证范围

- 检查中发现并修复初次选图误判为已采用、未完成日期传入旧表单计算两个功能问题；保留失败与补验记录，没有把中断算成完整通过。
