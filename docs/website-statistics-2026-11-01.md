# 运营总览网站数据与精选短评留白

本批按用户手机截图修正精选短评标签贴边，并在原运营总览加入可用于判断迭代方向的真实业务汇总。图标、认证和食堂评分位置／分页逻辑沿用已有版本。

## 界面和使用范围

“神评／同学说”区域增加左右12px内边距、10px内容间距，正文保留可收缩宽度和原有展开全文能力；点赞仍有44px操作目标，没有修改真实评分、评论或热度数字。

运营总览新增“网站数据”，提供近7／30天、正常账号、新增账号、参与账号、新增走势、功能参与排行及待跟进反馈／意见入口。使用原有Vue工作区，没有新增外部分析平台、浏览追踪、Cookie、设备标识或统计明细库。

参与比较使用“账号”，不声称已完成真人去重。主指标常显，口径按需展开；低参与不能单独证明功能不好用。统计只供有效的本校管理员读取，不返回对话、项目、课表、反馈正文、账号列表或个人联系信息。

## 指标定义和来源

当前学校、当前正常账号（`users.status=1`）；7／30个北京时间自然日，包含尚未结束的今天。下界为首日00:00，上界为服务读取时刻（不含上界），结果提供实际 `asOf`。读取在只读可重复读事务内完成。

| 指标 | 当前保留来源与口径 |
| --- | --- |
| 正常账号 | `users.school_id`及状态，不包含外校或禁用账号 |
| 新增账号／走势 | 上述账号的`created_at`，缺记录日期填真实0；7天逐日、30天每7天汇总为5组，末组2天，不冒充自然周 |
| 参与账号 | 下列来源在时间窗内的账号去重并集，不是各功能人数相加 |
| 校园问答参与 | `ai_model_usage.created_at`及`ai_message_feedback.updated_at`；保留用量仍计入，不等于现有对话条数或所有模型尝试 |
| 食堂参与 | 评分`updated_at`、短评`created_at`、点赞`created_at`；学校字段须匹配当前账号学校，同一账号多家评分仍只计一个参与账号 |
| 课表参与 | 原图及结构化课表的`imported_at`，同一账号跨两表不重复；不读取图片或课程JSON |
| 校园墙参与 | 帖子／回复和点赞的`created_at`，同时核对记录与当前账号学校 |
| 学习项目参与 | `student_projects.updated_at`，统计最近保存的保留记录，不读取项目材料JSON |
| 待跟进AI反馈 | 当前正常本校账号、窗口内更新的负面反馈，排除已在反馈更新时间之后处理的记录 |
| 待处理意见 | 本校、窗口内创建且当前`NEW`的保留意见；无学校归属的公共联系不混入本校指标 |

同一账号可参与多个功能。当前所属学校和保留记录决定统计范围；删除、撤回、归属和状态变化会影响结果。修改不按点击次数累计，没有追溯制造历史事件。页面浏览量、独立访客、纯浏览／未保存操作、完整请求失败率和留存率尚无采集口径，未显示为真实0或完成率，也不据此给出自动开发结论。

原总览“未处理意见”汇总同步收紧为本校范围，与原标签一致，未扩大管理权限。

## 接口与验证

`GET /api/admin/website-statistics?days=7|30`：检查JWT管理员角色及数据库当前账号角色、状态和学校；拒绝任意学校查询及其他窗口。返回`no-store`；数据库失败为503，界面显示重试而非假零。切换范围或账户会取消旧请求，晚到结果不能覆盖当前范围或新账号。

最终前端1316项、Java916项／17条件跳过／0失败错误，严格静态检查通过。首次前端新增的无效日期用例发现提示不统一，已修正日期校验并保留首次失败回执，再验通过；没有减弱用例。隔离H2验证真实SQL的学校／状态过滤、去重、时间边界、不同窗口与反馈处理；HTTP验证角色、学校、返回字段及缓存。前端验证真实零与缺失、范围／账号切换、取消、错误和30天图形分组。

数据检验基于隔离合成库及既有架构；没有通过自动工具读取正常生产管理员会话、没有伪造管理员账号或拿私人正文做验收。生产管理员的正向数据读取及新图形手机画面未由自动工具实测。当前浏览器操作能力仍不可用，不用CI或源码检查冒充真实手机视觉通过。
