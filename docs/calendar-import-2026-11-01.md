# 手机日历导入 · 2026-11-01

课表顶部增加“导入手机日历”。自动识别苹果、安卓和鸿蒙，不按固定型号或系统版本封锁入口；系统能力不可用时提供日历文件和收起的三步兼容方法。网页内提醒仍是独立开关。

## 用户实际看到的行为

| 系统 | 主动作 | 系统边界 |
| --- | --- | --- |
| iPhone／iPad | 打开私人只读课表订阅 | 在系统日历确认订阅，提醒按系统设置生效 |
| 安卓 | 支持文件分享时交给系统面板，否则保存 ICS | 需选择支持 ICS 的日历并确认；Google 日历手机版不支持统一批量文件导入 |
| 鸿蒙新旧版本 | 同样按文件分享能力处理，保留 ICS 文件导入路径 | 新版可从“添加 → 导入日程”进入；旧版无入口时需支持 ICS 的日历 |
| 内置浏览器 | 尝试同一主动作，失败后提示用系统浏览器 | 只复制公开课表入口，不在复制网址中附带登录凭据 |

这是一次网站点击发起的系统交接，不能跳过系统授权、应用选择或保存确认。浏览器撤销分享、拦截或需要再次用户手势时分别显示真实状态；没有“下载即导入成功”的假完成提示。兼容说明默认收起，不要求用户先选择型号或版本。

## 日程与隐私

仅导入本人保存的课表，范围为未来四周。钟点不完整时引导核对，不猜学校作息；取消课程和课前 5／10／15／30 分钟提醒保留现有 ICS 语义。客户端核对预览、归属、有效期、文件 MIME 与 SHA256；换号、换学校、退出会话和提前量变化清除旧准备状态。

苹果订阅仅在用户主动操作时创建，最长 180 天，地址需要保密。链接使用独立用途的签名及随机标识，服务端每次检查授权记录、账户可用状态、学校归属与到期时间；提供明确停用入口。邮件找回重置密码会撤销该账户的日历授权。手机已经保存的日程需要在系统日历移除，停用网址不冒充删除手机数据。正常退出网站不会擅自取消用户的系统日历订阅。

复用已有账户授权表，无新增生产 DDL；没有采集手机日历内容、申请系统日历写入权限、配置新服务商密钥或修改教学／名单／后台任务开关。私人链接和测试凭据不写入交付回执或公共 Git。
