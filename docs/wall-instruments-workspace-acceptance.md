# 校园墙、仪器与学习工作区

日期：2026-09-24。代码实现与本地测试记录，不是生产发布证明。

## 实现范围

- 持久工作区：原ChatView作为登录后父布局，保留聊天状态；项目、食堂、个人信息、反馈、Pro、管理员和新入口在右侧呈现。桌面支持展开/还原，手机侧栏抽屉，减少动态效果偏好下关闭转场。
- 校园墙：纯文本主题/回复、分类、我的发布、分页、点赞及取消、撤回、举报；管理员审核/隐藏及版本冲突防护。没有向生产填入虚构帖子。演示主题仅在开发预览内存中。
- 25类仪器：电学、计量、力学传感、光学、实验室与自动化。各条目有用途、记录项、异常核对提示、原厂来源和适用范围；学习记录可新建私有项目，已有项目也有“仪器与调试”页签。
- 实验/作业辅导：明确表单、本地附件提取、用户确认后实际调用现有聊天API、引用链接保留、AI建议标识和私有项目归档。未声称AI回答已具备学科正确性验证。

## 数据与权限

- 新增campus_wall_entries、campus_wall_likes、campus_wall_reports三表，schema.sql初始化；默认PENDING，发布/回复需审核。
- 服务端每次从有效账号读取学校/身份，普通用户不能访问审核API；列表/详情/写入按学校隔离。前端隐藏入口不是唯一防线。
- 不对其他用户返回作者真实姓名、账号ID或举报者；这不是不可追溯匿名服务。学校绑定不等于实名认证学籍。
- 纯文本渲染，敏感联系方式/证件号基础规则拦截；规则不能覆盖所有隐私与攻击，保留人工审核、举报和撤回。
- 主题/回复请求UUID重试幂等；点赞/举报单账号单记录；审核revision比对避免过期操作覆盖。
- 写入每账号每分钟12次，单实例内存计数、上限10000个活跃窗口；多实例部署需共享限流，不宣称现有实现分布式防刷。
- 导出包含自己的墙内容、点赞、举报。撤回主题删除关联回复，账号删除由外键级联清理；备份保留期仍需运营确认。
- 帖子不自动进入知识库/模型；仪器记录不自动发送AI。学习辅导需单独确认发送，调用既有用量账本。

## 验证

- 前端Node测试59项通过：包括新增学习输入边界和仪器索引完整性。
- 后端当前全量171项，170通过、1项既有环境依赖测试跳过。新增WallServiceTest 6项及WallControllerTest 3项，覆盖学校/作者隔离、未审核不可见、回复父帖隐藏、幂等、举报、审核冲突、敏感信息、撤回/注销级联、有效账号/管理员核验。
- 最终修正后npm run build、目标JS/Vue文件ESLint、前后端测试及git diff --check通过。
- design/workspace-check.mjs使用独立Chrome测试开发内存适配器，不访问真实论坛数据库或AI；检验侧栏DOM持久、发帖/回复审核状态、仪器切换草稿、仪器存项目、辅导结果存项目、各页导航、手机布局和减少动态效果。
- 桌面1440×1000、手机390×844，共18个截图场景；自动检查无页面横向溢出、无未捕获浏览器错误。独立复核提出的后台导航布局、跨页滚动归顶、仪器保存就地报错三项均已修正并复核通过；这一结论不代表全站无缺陷。详见[设计交接](workspace-design-handoff.md)。
- 最终截图与results.json位于本地临时目录：`[local evidence retained privately]`。这是隔离演示证据，不是生产运行证据。

## 部署与未验证

1. 需要在原配置环境重启后端以载入新接口和建表；生产环境请按发布流程先备份。当前执行环境没有DB_PASSWORD、JWT_SECRET与DEEPSEEK_API_KEY，因此未从此环境重启后端。本轮未修改生产数据库、未部署、未提取正在运行进程的密码。
2. 真实MySQL的论坛完整CRUD/管理员审核、真实模型辅导质量与用量结算仍需测试账号联调。隔离预览成功不替代这些验收。
3. 25类不是“所有大学设备”，也不是本校库存。缺具体型号和课程规程时仅提供原理与记录提示。高压、旋转机械、激光等真实操作需现场教师；未做自动设备控制。
4. 没有扫描件OCR、通用公式引擎、学科推理正确性保证、实时多人编辑、付费优先调度、会员计费、预约/查重授权对接或广告投放。
5. 初版校园墙没有图片附件、私信、外部校园墙同步、全文搜索或自动知识沉淀。后续先看真实使用和审核工作量，避免为增加功能而收集更多私人数据。
