# 评分位置、商家热度和公开短评

用户要求评分后留在原地，刷新后才更新名次；商家默认按评分人数排列，已发布的短评可被其他用户查看，并优先展示高赞内容。

## 当前行为

- 本次目录读取保存排序快照。评分或点赞后，分数、人数、点赞和精选短评照常更新，当前商家不因接口返回新顺序而移动；重新加载目录后才更新排名。默认评分人数从多到少，同人数按真实均分、编号稳定排序；仍保留“评分最高”选项。
- 保存时不把整个目录切成加载画面。已有短评和表单在后台读回时继续挂载；保存完按实际滚动容器补偿卡片位移。用户在等待中滚动、触摸、操作键盘或离开账户后，不会被旧请求强制拉回。
- 公开短评读取按真实点赞数优先，同赞按更新时间、编号排序。每页20条，可继续加载；不再只有一个不可继续的前20条窗口。作者自己的评价单独读回，低赞或不在第一页时也不会丢失已保存文字。当前已展开的短评在点赞时更新真实数量，不突然清空或截断已加载页；再次读取按最新点赞排序。
- 精选短评从公开内容中选最高赞。没有新增浏览量统计，也没有用估计浏览量凑热度。
- 新发布并通过既有检查的短评，对同校登录用户可读。公开列表只含 `PUBLISHED`；历史待审核或隐藏内容不批量改状态，仅作者自己的单独读回可包含其未公开文字。既有举报、下架及每人每商家一票规则保留。
