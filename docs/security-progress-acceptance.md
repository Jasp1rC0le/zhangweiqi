# 统一登录、项目推进与隐私安全验收

日期：2026-09-23。仅本地实现与测试，未部署。整个P0–P5规划未全部完成。

## 已实现

- 普通登录后，服务器返回ADMIN才显示聊天侧栏和工作台的“管理后台”。首页和登录弹窗不再显示管理员入口。
- 后台与前台共用同一访问令牌及刷新流程；旧前端 `/admin/login` 转至同一守卫。管理员进入时仍请求服务器当前身份，但不再输入密码。不创建新权限、不修改任何账户角色。
- 所有受保护 `/api/admin/**` 先统一校验ADMIN，原控制器权限检查保留。撤销或角色失效会话不能通过服务器验证。
- 账户页展示最近100个有效会话的创建/到期时间，支持退出当前会话以外的全部会话。只从验证后的身份读取用户与会话，不接受客户端传入身份；不展示令牌摘要、IP或设备指纹。
- 认证接口响应禁止缓存；个人数据导出补上本人食堂评分及短评，并保留项目与版本导出。
- 聊天Markdown移除可执行内容、外部图片/媒体、表单和内联样式。仅可主动打开无内嵌凭据的HTTP/HTTPS链接，并设置noopener/noreferrer。
- 同源生产Caddy示例补充CSP、防嵌入和设备权限限制；这是部署模板，不表示线上已启用。若部署使用跨域API或外部资源，需要明确来源并重新验证策略，不能直接放宽成通配。
- 项目可选择历史版本，对照当前草稿查看各部分原文变化；旧项目空数据表不误报为变化。
- 答辩/汇报准备根据用户已有要求整理问题，展示有效材料依据；本人说明与原有备注同步，保存进项目版本，可单独导出Markdown。不调用模型，不预测教师命题、不保证通过。
- 页面说明兼容师生，但教师身份不等于管理权限，也不提供读取其他用户项目的能力。
- 提交前缺项检查新增本人复核理由和前后问题数量提示。复核理由随私有项目版本保存、参与版本对比及导出；绑定规则版本和材料快照摘要，修改要求/正文/证据后明确提示旧理由需重核。反馈不减少问题数、不提高覆盖率、不代表系统确认误报。最多100条，每条500字；服务端校验结构和重复键，旧项目兼容。旧后端不支持新字段时拒绝提交，防止静默丢失。

## 本轮验证证据

- 前端Node测试38项通过；生产构建通过；本轮变更的Vue/JS及设计验收文件ESLint通过。
- 后端 `mvn test -q` 成功：138项测试，137通过、1项已有MySQL依赖测试跳过，0失败/错误。新增覆盖统一管理权限、撤销会话、会话操作身份注入防护、本人数据导出范围、复核记录版本保留/所有者隔离/输入校验；不等于真实MySQL端到端通过。
- 真实浏览器当前非管理员登录：无管理按钮，直接输入 `/admin` 被重定向 `/chat`。未使用真实管理员账号做正向端到端登录；对应共享会话和服务器权限路径由代码及测试覆盖。
- 内存隔离预览：答辩备注保存生成v2，旧v1对比能看到真实变化，未覆盖草稿；修复旧版本空CSV造成的虚假差异。
- 安全渲染预览：正文区域危险标签计数0、事件/内联样式属性计数0；正常文本、格式和官方链接保留，javascript链接无href。
- 桌面与390px手机预览：会话按钮、汇报输入、版本对比可读；手机内容宽度375px与滚动宽度相同。手机为浏览器视口模拟，不是实体设备测试。
- 内存示例复核闭环：原始1/2覆盖、1处缺项→填写理由→保存v2，覆盖与缺项数不变→修改正文后操作禁用→重新检查显示旧理由失效→保存v3。桌面/390px表单无溢出，未操作真实项目数据。

## 建议的新服务边界

兼职：审核、有效期、来源和原文跳转优先；不代收押金。可核验来源为[学校校企合作处](https://xqhzc.tsguas.edu.cn/)。场馆：正式入口和提醒优先，授权后才接预约，不绕过验证码、限额或学校规则。查重：先[知网官方跳转](https://cx.cnki.net/)，授权后再接站内检测；不得伪造检测率或默认上传未公开论文。以上为方案，不是新增服务已经上线。
