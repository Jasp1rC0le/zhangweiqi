# 运营与备案准备边界

本仓库提供开发和部署配置示例，不表示项目已获得公网运营所需批准。本次源码发布不办理备案、不改变域名或服务器、不部署应用。

正式开放服务前，由运营负责人根据实际主体、服务器地区、域名和服务内容，向所用云服务商及主管机构核对适用要求，准备真实有效的资料。不要把个人证件、登记文件、控制台截图、授权码或申请材料提交到代码仓库。

前端的主体名称、ICP 和公安备案字段仅在取得真实信息后填写，不能生成虚构号码；后端隐私配置也应与真实运营情况一致。

具体技术准备见 [上线前检查](launch-readiness.md) 和 [运行手册](free-launch-runbook.md)。本机已有的详细运营工作记录单独保留。
