# Campthink 项目总体规划

本页整合软件定位与开发边界。维护者本机的研究原件、招生材料、详细运营记录和用户提供的资料不随源码发布；原本机档案继续保留。

## 当前定位

面向校园学生与教师的 AI 问答和学习工作台。校园事实应关联可追溯来源；个人项目和附件由用户控制，不因使用通用工具而自动公开，也不因教师身份而获得管理员权限。

## 当前实现

应用已包含账号和会话、流式 AI 问答、校园知识维护与版本、后台检索评测、私有项目、有限数据与公式检查、附件文字提取、指定同校账号版本审阅、校园墙、食堂评分，以及费用和额度管理。入口、运行方式和具体边界见 [README](../README.md)。

管理员在正常权限流程内审核资料、帖子与评论。公开校园信息需核对学校、来源、发布日期和有效期；用户纠错或模型生成不能自动升级为正式事实。

## 后续方向

1. 在受控测试数据上持续验证账号隔离、项目版本、知识来源及异常恢复。
2. 按实际数据量改进检索质量和后台维护工具，保留资料审核与版本追溯。
3. 获得授权的课程样例后，再扩展专业工具并建立可复算的测试集。
4. 只有在真实需求、成本、运营与支付条件明确后，再考虑商业权益。

以上是规划，不代表已实现。通用 OCR、通用 Excel 兼容、专业结论认证、实时共同编辑、支付与会员权益不属于当前已完成承诺。

## 发布原则

规则工具与 AI 生成分别标识；未知成本不按零费用展示；不以本地单元测试替代真实邮件、模型供应商、公网 HTTPS 或数据库恢复验收。生产前提见 [发布检查表](launch-readiness.md)。
