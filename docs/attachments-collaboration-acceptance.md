# 附件、专业工具与定向审阅

日期：2026-09-23。记录本地增量，不是线上发布或合规认证。

## 本轮实现

- 菜单“账户与隐私”改为“个人信息”，采用中性色；警告红保留给退出/危险操作。保留原有首页与登录页面。按Impeccable既有产品约束处理清晰文案、错误状态和移动布局，不另起视觉体系。
- 原始附件只在浏览器Worker解析，先预览再确认，保存项目时才提交提取文字；不自动调用模型。支持PDF文本（页码标记）、DOCX段落、XLSX可见工作表和UTF-8文本。失败、取消、格式错误不覆盖旧材料。
- 文件最多10MB，PDF50页，提取文字5万字（任务要求2万），解析20秒超时终止。Office包最多500项、单个选中XML2MB、合计4MB；拒绝危险路径、宏/嵌入对象和XML外部实体。XLSX最多10个可见表、30列、2001行，公式用“未计算”标记，绝不把旧缓存冒充重算结果。
- 原创通用练习：校园调查报告、重复测量实验、通用项目。要求默认待确认，无虚构调查数据，不是天津中德应用技术大学的官方任务书。
- 数据检查新增中位数、样本标准差（n−1）、配对偏差/MAE/RMSE及参与行数；沿用原始行定位，明确剔除不适用行，不做显著性推断，不保证专业结论。统计随Markdown导出。
- 定向审阅：只能选择自己的已保存版本，指定已存在的同校账号；默认仅任务要求与清单，材料/证据和数据各自明确勾选。个人备注、本人复核理由和其他版本不共享。7天只读，接收者写意见但不能改原项目；支持撤销并清除快照/意见。API逐次核验参与账号、状态、到期和所有权，无管理员越权通道。每个所有者最多50条保留邀请记录。
- Token独立账本：预留、结算、失败退回在独立事务执行；使用持久化ID与行锁保证重复回调不重复扣减/退回；按原始预留日结算。个人信息显示本人最近50条，不含提问正文。旧记录不补造；进程中断遗留的预留需核对，不自动当作失败退款。
- 账户导出包含本人审阅记录/意见和额度记录；项目删除、相关账户注销通过外键清理。撤销不能收回对方已经复制的内容；数据库备份保留期限仍需运营方确认。
